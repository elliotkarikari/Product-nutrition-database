# Contributing

## Code

- Run the test suite before proposing a change: `PYTHONPATH=src python3 -m unittest discover -s tests`.
- Scorers and transforms must ship with fixtures. A calculation without a test is unfinished.

## Data

A data contribution is only acceptable with its evidence:

- the source and dataset release it came from;
- the licence that permits its use, and what use it permits;
- the collection or analysis period, where known;
- the method (analysis, specification, label, calculation, estimate).

Do not contribute data copied from a source whose terms you have not checked. Do not contribute scraped data from a source whose terms forbid it. When in doubt, open a source-register entry first and let the licence question be answered before any values move.

## Matches

Match corrections are welcome. State the basis: exact product evidence, generic entry, sample data or judgement. Reviewed matches are frozen into releases; a correction creates a new decision that supersedes the old one, it does not rewrite history.
