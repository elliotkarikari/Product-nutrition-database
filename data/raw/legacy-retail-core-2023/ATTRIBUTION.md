# Retail-shaped CoFID list (author-curated, 2023)

Copied byte for byte from `main`. Elliot Karikari curated it in the 2023 notebooks: which CoFID foods are sold at retail, and in what sale format. ShelfScale reads only two columns, the CoFID food code and the sale format, to know which foods are sold loose. Names and values always come from CoFID 2021 itself. Not a nutrient or weight source.
